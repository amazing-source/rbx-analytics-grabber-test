Two things that would corrupt this table if ignored

Merged funnels attach the wrong labels. The public analytics API will only serve funnel steps merged across funnels by step index. Merged, this game's two funnels blend into one and a “BaseUpgrade20” row appears carrying data even though that step has none. Every figure above is pulled per funnel name through the browser path instead.

The newest two cohort days always read low on deep steps, because a cohort needs time to reach them. Both are excluded from the means above.

A quest that pays for returning ran through this window

Read D1 with this in front of you

The 04.09 build added a 4-day quest track offered only to new players, with a Day 3 reward for coming back. While each cohort's timer is running, D1 through D4 measure reward-claiming as well as engagement. D1 read 19.19% on 4 September, the highest value in 28 days, against a 14.94% pre-update week.

This is stated as a property of the measurement, not as a judgement about the number. What would separate the two: D1 for cohorts arriving after the quest stops being offered, or D1 split by whether the player was eligible for it. Neither is available yet.
