4. Errors — how many, and what they are

Five script-error signatures appeared that do not exist on V1691. Roblox stamps each with the version it was first seen on; all five say V1698. Three are the same shape: a script asking for a UI element that isn't there. All are client-side — no new server-side signature has appeared at all, and the export is not truncated (8 rows against a 25-row cap), so that absence is real.

Why the top one matters: it fires inside UpdateView, the function that draws the pet bag when a player opens it, so that draw aborts partway. The pre-update baseline named this exact signature as the thing to watch — it stood at 3 events 13 minutes after the publish. Ninety minutes later it was at 33.

Two caveats before anyone panics.

  • Servers pick up a new build as they cycle, so part of 3 → 33 is simply more players on V1698, not the bug worsening per player.
  • Studio's export counts are not comparable to the analytics API's. The export tallied ~335 events across all signatures in 24 h on V1691; the API counted 1.4–2.8 million client script errors per day over the same period. So "33" ranks and dates a signature — it is not a count of affected players, and it cannot be converted into one: the lookup that joins error text to the API's volumes returns a 500 on this game.

Pre-existing on V1691 — for contrast, not action

Top signatures on the previous build over 24 h: 181 Player:Move called, but player currently has no humanoid (warning) · 52 Multiple StyleLinks under Children (warning) · 46 Roblox CoreGui re-entrancy (not our code) · 8 mesh decode failures · ~18 script timeouts in the GoShop raft UI · 11 SavePlayerData failed … invalid argument #1 to 'pairs' across two players, plus one PlayerData Load failed … READ_FAILED.

That last group is the open one: a save-failure path that permanently destroys a player's data. The counts are a floor — the message embeds the userId, so every affected player gets their own row and the export caps out. Server errors per player were flat across V1691, so it is a tail rather than a mass event, but it is the mechanism players described in the V1691 downvotes ("my game got reset", "my panda pet gone").
