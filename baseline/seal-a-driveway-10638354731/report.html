Client memory is flat at 18–21%, so there is no leak. Server frame rate is 59.95 against a 60 target, so the server is untouched. ClientFpsP10 fell 54.7 to 47.3, worst on Computer.

Supporting load: ~48 errors per DAU per day, 99.3% of them client-side — 11.7 million client errors on 25 August. For calibration, Become a Brainrot ran 110–130 per DAU when it was considered broken and ~30 after it was fixed.

Size: at 81,305 desktop DAU, closing the desktop rate to the phone rate is at least 659 fewer crashed sessions a day — a floor, since sessions outnumber DAU. Every one is a lost session on the platform that converts best: desktop payer conversion is 1.94% against phone's 0.83%.

The error export now names a likely cause — see What the errors say below. 85% of this game's entire error volume is a single dead input binding, and dead input bindings hurt keyboard platforms first.

With ARPPU flat at R$183–202 all window, this is one pass bought once.

82% of DAU is new every day, so revenue is currently a direct function of new-player inflow and almost nothing else. The day reach stops growing, revenue stops with it — and RFYL7PlayDays at 1.32 says reach will stop growing.

For an idle or simulator title this is the classic gap: repeatable DevProducts — currency packs, boosts, rebirth accelerators — are what let a retained player keep spending. At 4.3% that surface is effectively absent, and the game already has the loop to hang it on: rebirths, four truck tiers, five upgrade tracks.

This is upside, not a fault. Low ARPDAU alongside healthy concurrents would be the undertapped case; here ARPDAU is already high, which makes the missing repeatable surface more valuable, not less.

What the errors say

dashboard export
One signature is 85% of all error volume

An input binding that points at nothing

ContextActionService could not find the function passed in, doing nothing. — 10,468,796 events, client-side, first seen v488. Of 12,257,089 total events across 25 signatures, this is 85%.

The player presses something and nothing happens. That is functional, not cosmetic. It is also the leading candidate for the desktop concentration in finding 1 — ContextActionService is how keyboard and gamepad actions bind, so a dead binding lands hardest on exactly the platform whose crash rate quadrupled. Likely, not confirmed: the link needs a code read at v901.

Three more worth naming:

  • Native code generation of ReplicatedStorage.DrivewaySealer.SurfaceGrid failed — 3,650. Tiny count, real consequence: the core mechanic's script cannot be natively compiled, so it runs interpreted. That is a named, direct explanation for FPS P10 falling 54.7 → 47.3 while the server sits at 59.95.
  • 64-track animation limit exceeded — 1,596,039. Animations silently not playing; something loads tracks without releasing them.
  • Player appears to be spamming remote events — 42,801, server-side, first seen v884. Recent. Either an exploit surface or the game's own client over-firing; worth knowing which before it becomes a capacity problem.

Not material, named so nobody re-reports them: the mesh, sound and PBR load failures (~100k combined, all HTTP) and the DataStore queue warning — CDN flakiness and back-pressure, not defects in this build.

Open question

do not act yet
Unresolved — conversion fell ~31% on 24 August

Every split says the same thing. So does the calendar.

Payer conversion went 1.82% (23 Aug) to 1.37% to 1.25%, while DAU rose 17%. The numerator moved too, so this is not a denominator artifact: 3,778 payers to 3,051 — 727 fewer, on 35,343 more players.

What that rules out in one pass: not mix (new/returning flat at 83→82%, source mix flat); not one broken product (GamePass and DevProduct fell proportionally); not whales leaving (revenue per payer flat at R$190, 191, 183); not one platform (Computer, Phone and Tablet all fell ~30% together); not a deploy (v901 shipped 18 Aug and is still live). When every split agrees, the cause is global to the game.

Except that the fall lands exactly on Monday the 24th and Tuesday the 25th, and the three highest days in the series are Friday, Saturday and Sunday just before it. This game has only one prior week at anything like this scale, and in that week it was still ramping steeply — so a same-weekday comparison is not yet possible. The hourly revenue series shows a gradual evening-over-evening decline rather than a step at one hour, which argues against a config change at a moment.

The test: read payer conversion on Friday 28 and Saturday 29 August. Back to ~1.7–1.9% and it was the weekly shape and there is nothing here. Still ~1.25% and it is a real step — at which point the gap is worth roughly $26–29k a month. That range comes from two independent methods that agree; I have quoted both rather than one, because the whole figure rests on a baseline that may itself be a weekend peak.

What would overturn the healthy verdict

What to do

  1. Fix the dead ContextActionService binding. 10,468,796 events, 85% of all error volume, first seen v488. An input that does nothing is a functional defect and the leading explanation for the desktop crash rate. Confirm with a code read at v901, then measure on desktop crash rate: 1.12% now, target parity with phone at ~0.31%. Second: make DrivewaySealer.SurfaceGrid natively compilable — it is the core mechanic and currently runs interpreted.
  2. Read payer conversion on 28–29 August before anyone acts on the conversion move.
  3. Add repeatable DevProducts against the existing rebirth and upgrade ladders. Moving DevProduct share from 4.3% toward 15–20% on a game already at ARPDAU R$2.29 is a believable 20–50% revenue change with a named mechanism. Measure on revenue by source and ARPPU, two weeks after ship.
  4. Do not rebuild onboarding — it converts at 77.30% with only the final step leaking, the best in the portfolio. What is genuinely uninstrumented is the gap after Complete: the path from finishing the tutorial to the first rebirth, which no funnel covers.
  5. No badges exist on this universe at all. Badges are a cheap, visible progression hook and a Roblox surface; their complete absence on a game built around rebirths is an easy miss.
